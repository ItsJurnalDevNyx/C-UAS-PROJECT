# System Application Rescue & Smart Ambulance for Hospital

Aplikasi sistem manajemen tanggap darurat dan ambulans pintar yang menghubungkan pasien,
armada ambulans, dan pihak rumah sakit secara *real-time* untuk mempercepat respon medis gawat darurat.

---

## Fitur Utama

1. Smart Ambulance Tracking
2. Hospital Command Center
3. Rescue & Dispatch System
